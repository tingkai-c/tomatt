## Timer behavior
I want an option to enable pause on break finish and pause on work finish in the settings.

Also, I want option to automatically extend work session when the work timer finishes so that we don't automatically start break and interrupt user's focus, and instead extend the work session until the user decides to take a break. We can send a notification to the user when the work timer finishes.

## Automatically resume on app launch
I want the app to have a restore feature that could continue previous timer even if the app is force-quit and restarted.
The timer should still be going. Like if the user had a 30 minute working, and the app exited after 10 minutes, restarted after 5 more minutes, the timer should have 15 minutes remaining. But if the app restarted after an hour, it should just be at 30 minutes finished state(if the user has the pause on work finish/break finish), and not extending beyond 30 minutes(if the user has the extend work session enabled)
